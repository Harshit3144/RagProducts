RagProducts 🤖

An AI-powered Python project exploring Retrieval-Augmented Generation (RAG), document loading, AI agents, and tool calling. The project is organized into modular Python files for experimenting with document processing, intelligent tool execution, news summarization, and information retrieval.

🚀 Features
Document Loaders — A dedicated module for loading documents for further processing.
AI Agent — Agent-related functionality implemented in aiagent.py.
Tool Calling — Python modules for integrating tool execution into AI workflows.
News Summarization — A module for summarizing news and presenting key information.
Weather and Latest News — Exploring tool-based access to weather information and recent news.
Modular Architecture — Separate Python files to organize different project functionalities.
